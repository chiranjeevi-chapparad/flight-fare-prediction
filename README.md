# Flight Fare Prediction

## Project Overview
This project focuses on analyzing flight ticket pricing data and developing a machine learning solution to predict flight fares based on relevant flight attributes.

## Objectives
- Explore and understand flight fare data.
- Perform data cleaning and exploratory data analysis (EDA).
- Identify factors that influence flight ticket prices.
- Apply machine learning regression techniques to predict fares.
- Evaluate model performance using appropriate metrics.

## Tools & Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook
- Excel

## Dataset
The project uses the Flight Fare Dataset provided as an Excel file.

**Original dataset source:**  
https://d3ilbtxij3aepc.cloudfront.net/projects/CDS-Capstone-Projects/flight-fare.zip

The dataset is included in the `Dataset` folder.

## Installation

Clone the repository:

```bash
git clone https://github.com/chiranjeevi-chapparad/flight-fare-prediction.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Open Jupyter Notebook:

```bash
jupyter notebook
```
